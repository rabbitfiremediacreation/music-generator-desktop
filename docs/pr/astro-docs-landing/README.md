# Documentation design evidence

Actual browser captures of the production Astro build, taken on 27 October 2026 at a 1280 × 900 viewport:

- `landing-de.png`: German product landing page, studio design, download and installation entry points.
- `installation-de.png`: German installation guide with the custom dark documentation theme.

The product screenshot embedded in the landing page comes from `assets/music-generator-overview.png`, the existing app capture dated 25 October 2026. It contains sample song/library data and is labelled accordingly. These images show the documentation interface, not a newly performed desktop installation.

Browser QA also covered the English landing page, 390 px mobile layout, image zoom and Escape dismissal, language switching, Mac download alternatives, both documentation themes and production search. Download targets and SHA-256 links were checked against the published v0.1.2 release assets.
