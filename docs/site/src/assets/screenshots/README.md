# Installation screenshot provenance

Add screenshots from real installations here. The initial scaffold contains no installation screenshots; Lee and other contributors can supply them in follow-up pull requests.

For each file record:

| File | App version | OS version | Hardware | UI language | Capture date | Step / source |
| --- | --- | --- | --- | --- | --- | --- |

Use the filename in the first column and an issue or PR link in the last column when available. Include the locale in filenames if the screenshot contains localized UI. The site's contributor guide explains relative image paths and translated alt text.
